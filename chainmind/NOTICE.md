# Chain Mind

Made by Suvhankar Dutta.

Version 0.2.0. Carries a conversation from one AI assistant to another, shows
how much context is left, and says where to go next when it runs out.

Attribution appears in four places, so it survives a partial copy of the code:

- the header comment on every source file
- the extension description on `chrome://extensions`
- the footer of the in-page gauge panel
- the footer of the toolbar popup

If you fork this, keep the header comments or replace them honestly. Removing an
author line from a file you did not write is the one change that costs the
person who did.
